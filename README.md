# OnlineBookStore Sales SQL Analysis

## Project Overview
Exploratory and sales analysis of an online bookstore database using SQL. The project analyzes customer purchasing behavior, book inventory, genre performance, and order trends across three relational tables (`Books`, `Customers`, and `Orders`).

## Dataset Files
- `Books.csv`: Book details including title, author, genre, price, and available stock.
- `Customers.csv`: Customer demographics and location details.
- `Orders.csv`: Order transactions linking customers and books with order dates, quantities, and total amounts.
- `dashboard in SQL.sql`: Complete SQL queries answering key business questions.

## Key SQL Concepts Used
- Multi-table `JOIN`s (`INNER JOIN`, `LEFT JOIN`)
- Aggregations (`SUM`, `COUNT`, `AVG`, `GROUP BY`, `HAVING`)
- Filtering, sorting, and date-based sales analysis
- Subqueries / CTEs and ranking functions
